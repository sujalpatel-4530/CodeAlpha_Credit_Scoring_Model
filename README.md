# Credit Scoring Model

## Overview
This project predicts whether a loan applicant is eligible for a loan using Machine Learning techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Jupyter Notebook

## Dataset
The dataset contains applicant information such as:
- Gender
- Marital Status
- Income
- Loan Amount
- Credit History
